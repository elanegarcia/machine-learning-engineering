# Engenharia de Machine Learning

Criei este repositório para reunir projetos práticos de Machine Learning Engineering, explorando o ciclo de vida completo de soluções de Machine Learning: desde preparação dos dados e experimentação até treinamento, avaliação, deploy, monitoramento e evolução dos modelos.

O objetivo é aplicar conceitos de Machine Learning combinados a boas práticas de Engenharia de Software, Dados e MLOps, construindo soluções reproduzíveis, escaláveis e preparadas para ambientes produtivos.

## Sobre o repositório

Os projetos deste portfólio irão abordar diferentes etapas do ciclo de Machine Learning, incluindo:

- Análise e preparação de dados
- Feature Engineering
- Treinamento e validação de modelos
- Machine Learning supervisionado e não supervisionado
- Seleção e avaliação de métricas
- Experimentação
- Pipelines de Machine Learning
- Model Serving
- APIs para inferência
- Batch e Real-Time Inference
- Monitoramento de modelos
- Data Drift e Model Drift
- MLOps
- Versionamento e reprodutibilidade
- CI/CD aplicado a Machine Learning
- Cloud Machine Learning
- Sistemas de recomendação
- NLP e Inteligência Artificial Generativa

## Projetos

Os projetos serão adicionados gradualmente (quando eu tiver tempo haha).

Cada projeto vai explorar não apenas a criação de um modelo, mas também os desafios de engenharia necessários para transformar experimentos de Machine Learning em soluções reproduzíveis e preparadas para produção.

### Em desenvolvimento

#### Sistema de Recomendação

Desenvolvimento de um sistema de recomendação end-to-end, explorando preparação de dados, feature engineering, treinamento, avaliação e disponibilização das recomendações.

**Tecnologias:** Python, Pandas, NumPy, Scikit-learn, SQL e Docker.

**Conceitos explorados:**

- Collaborative Filtering
- Content-Based Filtering
- Ranking
- Similaridade
- Precision@K
- Recall@K
- NDCG@K
- Experimentação offline
- Model Serving

---

#### Pipeline de Machine Learning

Construção de um pipeline reproduzível cobrindo preparação dos dados, treinamento, avaliação, versionamento e disponibilização de modelos.

**Tecnologias:** Python, Scikit-learn, Docker e CI/CD.

**Conceitos explorados:**

- Data Preparation
- Feature Engineering
- Training Pipeline
- Model Evaluation
- Model Versioning
- Automated Testing
- Model Deployment
- Monitoring
